# Modern Portfolio Website

A beautiful, interactive portfolio website built with vanilla HTML, CSS, and JavaScript featuring modern animations, particle effects, and a feedback system.

## 🌟 Features

### Visual Design
- **Particle Background**: Interactive particle.js animation with mouse interaction
- **Modern Gradients**: Beautiful gradient backgrounds and text effects
- **Smooth Animations**: Scroll-triggered animations and hover effects
- **Responsive Design**: Fully responsive across all device sizes
- **Glass Morphism**: Modern frosted glass effects

### Interactive Elements
- **Smooth Scrolling**: Seamless navigation between sections
- **Typing Effect**: Dynamic typing animation in hero section
- **Animated Counters**: Count-up animations for statistics
- **Skill Bars**: Animated progress bars for skills
- **Floating Icons**: Orbiting technology icons around profile

### Functionality
- **Feedback System**: Interactive star rating and feedback collection
- **Contact Form**: Functional contact form with validation
- **Local Storage**: Feedback is saved locally and persists between visits
- **Toast Notifications**: User-friendly success/error messages
- **Back to Top**: Smooth scroll to top functionality
- **Mobile Menu**: Responsive hamburger navigation

### Special Features
- **Easter Egg**: Hidden Konami code activation (↑↑↓↓←→←→BA)
- **Accessibility**: Skip links and keyboard navigation support
- **Performance**: Optimized with intersection observers and debounced scrolling
- **Developer Console**: Welcome message for curious developers

## 🚀 Getting Started

1. **Clone or Download** the files to your local machine
2. **Open `index.html`** in any modern web browser
3. **Customize** the content to match your personal information

## 📁 File Structure

```
portfolio/

```

## 🎨 Customization

### Personal Information
Edit the following sections in `index.html`:
- Hero section: Name, title, and description
- About section: Personal details and statistics
- Skills section: Your technical skills and percentages
- Projects section: Your portfolio projects
- Contact section: Your contact information

### Colors and Styling
The main color scheme uses CSS custom properties in `styles.css`:
- Primary gradient: `#667eea` to `#764ba2`
- Accent gradient: `#ff6b6b` to `#ffd93d`
- Text colors: Various shades of gray

### Content
- Replace placeholder project information with your actual projects
- Update social media links in the contact section
- Modify the skills and their proficiency levels
- Customize the about section with your experience

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px to 1199px
- **Mobile**: Below 768px
- **Small Mobile**: Below 480px

## 🔧 Dependencies

The portfolio uses minimal external dependencies:
- **Font Awesome 6.0.0**: For icons
- **Google Fonts (Poppins)**: For typography
- **Particles.js 2.0.0**: For background particle effects

All dependencies are loaded via CDN, so no local installation is required.
